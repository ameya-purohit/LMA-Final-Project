How to use. Open labels_<your name>.jsonl. For each answer, read the question, the gold answer and what the failing test showed on the old code, then label the answer, and label every citation. Answers are saved in this browser as you go. When all are done, click Export labels; it downloads labels_<your name>_done.jsonl. Send it back. The guide is docs/annotation_guide.md, Part 2.

Answer: correct = matches the gold behaviour; partial = part right (for example right behaviour, wrong place); incorrect = wrong behaviour. Citation: causal = changing this line would change the claimed behaviour; on-topic = about the same feature but does not decide it; irrelevant = unrelated. Judge each citation against the claim shown with it. Decide yourself; do not use an AI tool.
